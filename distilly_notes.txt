To test and run:

	•	`go test ./...` passes
	•	`npm run build` succeeds
	•	`wails build` produced src/build/bin/distilly.app

Run locally with 

`cd src && wails dev` 

Other commands in 'src'

`wails doctor` / `wails build` / `wails dev`

(Wails CLI is at ~/go/bin/wails)

Note: wails is not installed globally. It is only in this project (in go bin) - if needed globally, can install via Homebrew
